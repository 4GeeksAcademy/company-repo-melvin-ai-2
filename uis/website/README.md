# Brasaland Website

Public Next.js website for Brasaland customers in Colombia and Florida. It presents the brand, all 14 locations, menu positioning, contact information, and the Brasa Points registration flow.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Verify

```bash
npm run lint
npm run build
```

Routes:
- `/`: complete corporate landing page.
- `/brasa-points`: typed loyalty registration and validation.

This application does not expose APIs. Future submissions must use a service under the repository’s `services` folder.
